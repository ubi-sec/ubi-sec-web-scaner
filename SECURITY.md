# Security Policy

## Supported Versions

The following version is currently supported:

| Version | Supported |
| ------- | --------- |
| 2.0.x   | ✅ Yes     |
| < 2.0   | ❌ No      |

## Reporting a Vulnerability

If you discover a security vulnerability in **UBI-SEC Web Vulnerability Scanner**, please report it responsibly.

### Please do not

* Publicly disclose the vulnerability before it has been reviewed.
* Use the scanner against systems without authorization.
* Submit reports containing sensitive personal information or credentials.
* Use this project to attack or disrupt systems you do not own or have permission to test.

### How to Report

Please contact the project author privately with:

* A clear description of the vulnerability.
* Steps to reproduce the issue.
* Affected file, function, or component.
* Proof of concept, if applicable.
* Potential security impact.
* Suggested remediation, if known.

For security-related reports, please use the contact information available on the project's GitHub profile.

## Scope

Security reports may include issues affecting:

* Scanner code
* Dependency usage
* Report generation
* Input validation
* URL/request handling
* Local file handling
* Authentication or authorization mechanisms, if introduced in future versions

Issues in third-party dependencies should be reported to their respective maintainers when appropriate.

## Responsible Use

UBI-SEC Web Vulnerability Scanner is intended for:

* Authorized penetration testing
* Cybersecurity education
* CTF competitions
* Security research in controlled environments
* Testing your own applications
* Intentionally vulnerable applications and labs

Users are responsible for obtaining proper authorization before scanning any target.

The project author is not responsible for misuse of the scanner or damage caused by unauthorized testing.

## Security Improvements

Security improvements and vulnerability fixes may be incorporated into future releases.

When reporting a vulnerability, please provide enough technical information to reproduce and verify the issue without exposing unnecessary sensitive data.
